# 🚴 ZAPFIT - Обновление функционала

## Реализованные функции (версия 1.2.0)

### 📊 1. **Метрики формы - CTL/ATL/TSB**

**Компонент:** `FitnessMetrics.jsx`

Профессиональное отображение трех ключевых метрик тренировочной нагрузки:

- **CTL (Chronic Training Load)** - тренировочная нагрузка за 42 дня
  - Показывает общую подготовленность спортсмена
  - Растет при регулярных тренировках
  
- **ATL (Acute Training Load)** - острая нагрузка за 7 дней
  - Текущая нагрузка, которую организм испытывает
  - Быстро реагирует на интенсивные тренировки
  
- **TSB (Training Stress Balance)** - баланс тренировочного стресса
  - Вычисляется как: TSB = CTL - ATL
  - Показывает готовность к интенсивности:
    - \> 15: "Свежий" - хорошо для спринтов
    - 5-15: "Отличный" - оптимально для тренировок
    - -5 до 5: "Нейтральный" - сбалансированное состояние
    - -15 до -5: "Усталый" - время для восстановления
    - < -15: "Переутомлен" - нужен полный отдых

**График за 60 дней:** Визуализирует тренды всех трех метрик

### 🎯 3. **SMART Цели - Goal Setting**

**Компонент:** `GoalSetting.jsx`

Полноценная система управления целями с методологией SMART:

**Типы целей:**
- 🚴 **Расстояние** - километраж за период
- ⏱️ **Время тренировок** - часы в неделю/месяц
- 📅 **Частота** - количество дней тренировок
- 💪 **CTL** - целевая тренировочная нагрузка
- ⚖️ **Вес** - целевой вес спортсмена
- ✨ **Свои цели** - произвольные цели

**Функции:**
- Создание/редактирование целей
- Прогресс-бары с процентом выполнения
- Автоматический расчет дней до финиша
- Отслеживание между стартовой и целевой датой
- Удаление завершенных целей

**Примеры целей в приложении:**
- "Проехать 1000 км за месяц"
- "Улучшить CTL до 150"
- "Тренироваться 5 дней в неделю"

### 😴 4. **Сон и питание - Sleep & Nutrition Panel**

**Компонент:** `SleepNutritionPanel.jsx`

Интегрированное отслеживание восстановления и питания:

#### Вкладка "Сон":
- 😴 **Часы сна** - длительность ночного сна

- 7-9 часов: "✓ Оптимальное количество"

#### Вкладка "Питание":
- 🔥 **Калории** - ккал за день
- 🥩 **Белки** - граммы
- 🌾 **Углеводы** - граммы
- 🧈 **Жиры** - граммы
- 📝 **Примечания** - тип приема пищи

**Макросы рассчитываются и отслеживаются для:**
- Оптимизации восстановления
- Анализа питательной ценности
- Планирования диеты

## 🗄️ Структура базы данных

### Новые таблицы:

```sql
-- Метрики формы
CREATE TABLE fitness_data (
    id INTEGER PRIMARY KEY,
    date TEXT UNIQUE,
    ctl REAL,          -- Chronic Training Load
    atl REAL,          -- Acute Training Load
    tsb REAL,          -- Training Stress Balance
    created_at TEXT
);

-- SMART цели
CREATE TABLE goals (
    id INTEGER PRIMARY KEY,
    title TEXT,
    description TEXT,
    goal_type TEXT,    -- distance, duration, frequency, fitness, weight, custom
    target_value REAL,
    current_value REAL,
    unit TEXT,
    start_date TEXT,
    target_date TEXT,
    status TEXT,       -- active, completed, archived
    progress_percent INTEGER,
    created_at TEXT
);

-- Качество сна
CREATE TABLE sleep_data (
    id INTEGER PRIMARY KEY,
    date TEXT UNIQUE,
    sleep_duration_hours REAL,
    sleep_quality INTEGER,  -- 1-5
    notes TEXT,
    created_at TEXT
);

-- Питание
CREATE TABLE nutrition_data (
    id INTEGER PRIMARY KEY,
    date TEXT,
    calories INTEGER,
    protein REAL,
    carbs REAL,
    fat REAL,
    notes TEXT,
    created_at TEXT
);

-- Лента активности
CREATE TABLE activity_feed (
    id INTEGER PRIMARY KEY,
    event_type TEXT,   -- activity, achievement, goal, sleep, nutrition
    title TEXT,
    description TEXT,
    value REAL,
    icon TEXT,
    color TEXT,
    created_at TEXT
);
```

## 📊 Примеры расчетов

### CTL/ATL/TSB:

```javascript
// Формула экспоненциального взвешивания:
newCTL = oldCTL + (dailyTSS - oldCTL) / 42

// Пример:
dailyTSS = 150 (в день тренировки)
oldCTL = 100

newCTL = 100 + (150 - 100) / 42
       = 100 + 50 / 42
       = 100 + 1.19
       = 101.19
```

### Прогресс цели:

```javascript
// Времени прошло:
const elapsedDays = (now - startDate) / (1000 * 60 * 60 * 24)
const totalDays = (endDate - startDate) / (1000 * 60 * 60 * 24)
const timeProgress = (elapsedDays / totalDays) * 100

// Итоговый прогресс:
progress = max(timeProgress, actualProgress)
```

## 💡 Рекомендации

### Для тренировок:
- Поддерживайте CTL между 80-150 (в зависимости от уровня)
- Стремитесь к TSB в диапазоне 5-15 для важных событий
- После интенсивных недель допускайте ATL > CTL (негативный TSB)

### Для сна:
- Стремитесь к 7-9 часам в ночь
- Отслеживайте качество - оно важнее количества
- При интенсивных тренировках спите больше (8-9 часов)

### Для питания:
- Поддерживайте 1.6-2.2 г белка на кг веса
- 50-60% калорий из углеводов
- 20-30% из жиров
