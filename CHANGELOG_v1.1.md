# ZAPFIT v1.1.0 - Changelog

## 📋 Главные улучшения версии 1.1.0

### ✨ Новые функции

#### 1. **AI-Powered Training Plans** 🤖
- **Функция**: Автоматическая генерация оптимизированных тренировочных планов на 12 недель
- **Периодизация**: Поддержка линейной и волнообразной периодизации
- **Фазы тренировок**: Build → Peak → Taper/Recovery
- **Автосессии**: Генерация структурированных сессий для каждого дня недели
- **API**: Новый обработчик `generate-ai-plan` с использованием AI для анализа

#### 2. **Расширенная система целей** 🎯
- **Типы целей**: Distance, Duration, Elevation, Power, HR-based
- **SMART критерии**: Конкретные, измеримые, достижимые, релевантные, своевременные
- **Отслеживание прогресса**: Процент выполнения цели в реальном времени
- **Статусы**: Active, Paused, Completed, Failed
- **Таблица**: Новые колонки `goal_type`, `unit`, `start_date`, `target_date`, `progress_percent`

#### 3. **Улучшенное управление питанием** 🍽️
- **Стандартные блюда**: 70 предзагруженных блюд с БЖУ
- **Категории**: Каши, Макароны, Салаты, Яйца, Молочное, Мясо, Рыба, Фрукты, Овощи, Напитки, Сладости, Первые/Вторые блюда
- **Кастомные рецепты**: Создание собственных рецептов с сохранением БЖУ
- **Фильтрация**: По категориям с подсчетом блюд
- **Холодильник**: Полноценная система управления блюдами

#### 4. **Улучшенная система воды** 💧
- **Синхронизация**: Данные корректно синхронизируются между Dashboard и Water страницей
- **Таблицы**: Оптимизирована структура `water_entries` и `water`
- **Миграции**: Автоматическое добавление недостающих колонок
- **Исправления**: Corrected column naming (`created_at` → `time`)

#### 5. **Календарь с полным функционалом** 📅
- **Тренировки**: Отображение тренировочных сессий из плана
- **Вода**: История потребления воды
- **Соревнования**: Отображение запланированных соревнований
- **Детали дня**: Всплывающий модал с полной информацией
- **Синхронизация**: Real-time обновление при создании планов

#### 6. **Система загрузки фото** 📸
- **Загрузка**: Поддержка загрузки фото для активностей
- **Сохранение**: JSON-сериализация путей к фото
- **Таблица**: Новая колонка `photos` в таблице `activities`
- **Миграция**: Автоматическое добавление колонки для старых БД

#### 7. **Полная структура БД** 🗄️
Новые таблицы:
- `training_weeks` - Недели тренировочного плана
- `training_sessions` - Сессии тренировок
- `sleep_data` - Данные о сне
- `dish_categories` - Категории блюд
- `fitness_data` (расширена) - CTL, ATL, TSB метрики
- `goals` (расширена) - Расширенные цели

### 🔧 Технические изменения

#### IPC Handlers (новые/обновленные)
- `generate-ai-plan` - Генерация тренировочного плана (НОВЫЙ)
- `create-training-plan` - Создание плана (ОБНОВЛЕН с логированием)
- `get-training-plan-detail` - Получение деталей плана
- `update-activity-photos` - Сохранение фото активностей (НОВЫЙ)
- `get-standard-dishes` - Загрузка стандартных блюд (ОБНОВЛЕН)
- `get-dish-categories` - Получение категорий блюд (НОВЫЙ)
- `add-dish-category` - Добавление категории (НОВЫЙ)
- `get-fitness-metrics` - Получение fitness данных (ИСПРАВЛЕНО)

#### Компоненты React (обновлены)
- `Calendar.jsx` - Полная поддержка тренировок, воды, соревнований
- `GoalSetting.jsx` - Расширенная система целей с SMART
- `NutritionTabContent.jsx` - Загрузка стандартных блюд
- `FridgeTabContent.jsx` - Холодильник с фильтрацией
- `TrainingPlans.jsx` - Синхронизация с календарем
- `RideModal.jsx` - Загрузка фото

#### Database (db.js)
- Новая миграция система для ALTER TABLE
- Автоматическая переинициализация стандартных блюд
- Улучшенное логирование инициализации
- Поддержка новых таблиц и колонок

#### Preload API (preload/index.js)
- `generateAIPlan()` - Генерация AI плана
- Все остальные API методы остались совместимыми

### 🚀 Как обновиться

#### Для пользователей desktop:
1. Скачать новый ZAPFIT Setup 1.1.0.exe
2. Удалить старую версию
3. Установить новую версию
4. Старая БД автоматически обновится (миграции)

#### Для Docker:
```bash
docker pull [ваш-registry]/zapfit:1.1.0
docker run -p 8000:5000 zapfit:1.1.0
```
