# 🔧 Исправление ошибки Strava 401 (activity:read_permission)

## ❌ Проблема
```
Ошибка: Strava API error: 401 - 
{"message":"Authorization Error","errors":[{"resource":"AccessToken","field":"activity:read_permission","code":"missing"}]}
```

Это значит, что ваш токен получен **БЕЗ** прав на чтение активностей.

---

## ✅ Решение (пошагово)

### Шаг 1: Откройте Dashboard Strava
- Перейдите на: **https://developer.strava.com/dashboard**
- Войдите в свой аккаунт Strava (если требуется)

### Шаг 2: Найдите приложение DataImporter
- На левой панели найдите приложение **"DataImporter"**
- Нажмите на него, чтобы открыть настройки

### Шаг 3: Нажмите "View Authorization"
- В главной области приложения найдите кнопку **"View Authorization"**
- Нажмите её

### Шаг 4: Проверьте и выберите Scope
На странице авторизации вы увидите флажки для разрешений:
- ✅ Убедитесь, что **ВСЕ** из этих выбраны:
  - [ ] `read` (базовое чтение)
  - [ ] `read_all` (опционально)
  - [x] **`activity:read`** ← ОБЯЗАТЕЛЬНО!
  - [x] **`activity:read_all`** ← ОБЯЗАТЕЛЬНО!

**Если их нет в списке:**
1. Вернитесь в Dashboard
2. Найдите раздел "Authorization Scopes"
3. Отметьте `activity:read` и `activity:read_all`
4. Сохраните
5. Повторите Шаг 3

### Шаг 5: Получите новый токен
- После выбора правильных scope нажмите кнопку "Authorize" или "Generate Token"
- Вы получите:
  - **Access Token** - скопируйте его
  - **Client ID** - скопируйте (опционально)
  - **Client Secret** - скопируйте (опционально)

### Шаг 6: Вставьте токен в приложение
1. Откройте straveFlow
2. Нажмите **Settings (⚙️)**
3. Найдите раздел **"Strava API"**
4. Вставьте **Access Token** в первое поле
5. (Опционально) Вставьте Client ID и Secret
6. Нажмите **"Сохранить"**
7. Нажмите **"Импортировать"**

---

## 📋 Проверочный список

Перед импортом убедитесь:
- [ ] Access Token вставлен и НЕ пустой
- [ ] Access Token содержит правильные scope (activity:read)
- [ ] Вы нажали "Сохранить" перед импортом
- [ ] Client ID НЕ требуется (опционально)
- [ ] Токен еще не истёк (сроком на 6 часов)

---

## 🆘 Если всё ещё не работает

1. **Откройте Developer Tools** (F12 в приложении)
2. **Перейдите на вкладку "Console"**
3. **Попробуйте импортировать снова**
4. **Скопируйте полное сообщение об ошибке**
5. **Проверьте, совпадает ли токен в поле с сгенерированным на Strava**
